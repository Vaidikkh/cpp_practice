## Compilation

Using g++:

```bash
g++ filename.cpp -o program.exe
```

Example:

```bash
g++ pointers.cpp -o pointers.exe
```

Run:

```bash
./pointers.exe
```

or on Windows:

```powershell
.\pointers.exe
```
